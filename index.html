Kaise kaam karta hai

  1. 1
    Bolo. Mic se Hindi/Hinglish me shikayat bolo, ya type karo.
  2. 2
    Samjho. TF-IDF + Logistic Regression model shikayat ko 6 categories me se ek me daalta hai.
  3. 3
    Route karo. Category ke hisab se sahi team ya department suggest hota hai, priority ke saath.
  4. 4
    Suno. Result wapas bolke sunaya jata hai — padhna ya type karna zaroori nahi.

Honest note

Ye ek demo hai: classifier 144 synthetic sample complaints par train hua hai, isliye iski accuracy production model jaisi nahi hai. Live demo me awaaz ke liye browser ki built-in Web Speech API use hoti hai (koi key ya server nahi chahiye). Production design me Gnani AI ke models hain — Prisma v2.5 (speech-to-text), Evon v3.3 (reasoning) aur Timbre v2.5 (text-to-speech). Tumhari awaaz ya shikayat kahin store nahi hoti.
